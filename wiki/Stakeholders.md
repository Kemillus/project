# Заинтересованные стороны (Stakeholders)

В данном разделе представлен реестр заинтересованных сторон проекта HabitTrackerBot и матрица "Интерес / Влияние".

## Реестр заинтересованных сторон

| Стейкхолдер | Роль и интерес | Влияние | Стратегия взаимодействия |
| :--- | :--- | :---: | :--- |
| **1. Команда разработки** | Разработка, дизайн, поддержка. Интерес: успешное завершение проекта, получение опыта и оценки, портфолио. | Высокое | Тесное взаимодействие, ежедневные/еженедельные синки, прозрачное распределение задач. |
| **2. Менеджер проекта** | Управление процессом, соблюдение сроков. Интерес: сдача проекта в срок, соответствие требованиям. | Высокое | Принятие ключевых решений, мониторинг прогресса, координация команды. |
| **3. Заказчик / Преподаватель** | Приемка результатов. Интерес: соответствие проекта академическим требованиям, применение студентами знаний на практике. | Высокое | Регулярная отчетность о статусе проекта, демонстрация промежуточных результатов (спринтов). |
| **4. Конечные пользователи** | Использование бота для трекинга привычек. Интерес: удобство использования, отсутствие багов, полезность продукта. | Среднее | Сбор обратной связи, проведение бета-тестирования, опросы, учет пожеланий в бэклоге. |
| **5. Telegram (как платформа)** | Предоставление инфраструктуры и API для бота. Интерес: соблюдение правил платформы, отсутствие спама со стороны бота. | Высокое | Мониторинг изменений в документации Telegram API, соблюдение ограничений на отправку сообщений (rate limits). |
| **6. Провайдер хостинга/сервера** | Обеспечение бесперебойной работы кода и БД. Интерес: своевременная оплата услуг. | Низкое | Своевременная оплата счетов, мониторинг доступности сервера (uptime). |
| **7. Инвестор (если привлекается)** | Финансирование проекта. Интерес: возврат инвестиций, прибыльность (рост NPV), достижение точки безубыточности. | Среднее | Регулярные финансовые и метрические отчеты, презентация планов развития и монетизации. |

---

## Матрица «Интерес / Влияние»

| | **Низкий интерес** | **Высокий интерес** |
| :--- | :--- | :--- |
| **Высокое влияние** | 5. Telegram (как платформа) | 1. Команда разработки <br> 2. Менеджер проекта <br> 3. Заказчик / Преподаватель |
| **Низкое влияние** | 6. Провайдер хостинга | 4. Конечные пользователи <br> 7. Инвестор (на ранних стадиях) |

> *Примечание к матрице:*
> - Квадрант "Высокое влияние / Высокий интерес" требует максимального внимания и плотного управления.
> - Квадрант "Высокое влияние / Низкий интерес" (Telegram) требует удовлетворения базовых требований (Keep Satisfied), чтобы не заблокировали бота.
> - Стороны с высоким интересом, но низким влиянием (пользователи) нужно информировать (Keep Informed).
> - Стороны с низким интересом и низким влиянием (хостинг) требуют минимальных усилий (Monitor).
