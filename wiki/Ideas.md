# Идеи проектов

## Идея 1: Telegram-бот для трекинга привычек "HabitTrackerBot"

- **Название идеи:** Telegram-бот для трекинга привычек.
- **Потребность (какая проблема решается):** Людям сложно вырабатывать новые полезные привычки и отслеживать их регулярность без простого и всегда доступного инструмента. Существующие приложения часто перегружены функциями.
- **Основные результаты проекта (ключевая функциональность):**
  - Добавление, редактирование и удаление привычек.
  - Ежедневные напоминания о необходимости выполнить действие.
  - Отметка о выполнении привычки (да/нет).
  - Просмотр статистики за неделю и месяц.
- **Потенциальный рынок и целевая аудитория:** Широкая аудитория пользователей мессенджера Telegram (студенты, школьники, работающие люди), желающие улучшить свою продуктивность и дисциплину.
- **Примерные сроки вывода продукта на рынок (MVP и развитие):**
  - MVP: 3-4 недели.
  - Дальнейшее развитие (интеграция геймификации, социальные функции): 2-3 месяца.
- **Технологии:** Python, Aiogram (или Telebot), PostgreSQL / SQLite, Docker.
- **Оценка рисков и технической сложности:**
  - Риски: Низкий уровень удержания пользователей, высокая конкуренция.
  - Техническая сложность: Низкая-средняя (базовая интеграция с Telegram API, работа с базой данных).

## Идея 2: Мини-скрипт парсинга конспектов в карточки для интервального повторения

- **Название идеи:** Скрипт "NotesToCards".
- **Потребность (какая проблема решается):** Студенты тратят много времени на ручное создание флеш-карточек (например, для Anki) из своих текстовых конспектов при подготовке к экзаменам.
- **Основные результаты проекта (ключевая функциональность):**
  - Загрузка текстового файла с конспектом (Markdown или TXT).
  - Автоматическое распознавание терминов и определений с помощью LLM (или регулярных выражений).
  - Экспорт сгенерированных карточек в формат, поддерживаемый Anki (.csv, .apkg).
- **Потенциальный рынок и целевая аудитория:** Студенты вузов, школьники старших классов, люди, изучающие иностранные языки.
- **Примерные сроки вывода продукта на рынок (MVP и развитие):**
  - MVP: 2-3 недели.
  - Дальнейшее развитие (веб-интерфейс, поддержка форматов PDF/Word): 1-2 месяца.
- **Технологии:** Python, OpenAI API / локальная LLM, библиотека `genanki`.
- **Оценка рисков и технической сложности:**
  - Риски: Низкое качество автоматической генерации карточек, зависимость от сторонних API (LLM).
  - Техническая сложность: Средняя (работа с парсингом текста и интеграция с LLM).

## Идея 3: Сайт-справочник по алгоритмам на GitHub Pages

- **Название идеи:** Сайт-справочник "AlgoCheatSheet".
- **Потребность (какая проблема решается):** Начинающие программисты нуждаются в структурированном, понятном и быстром доступе к примерам реализации базовых алгоритмов и структур данных на разных языках, без необходимости искать информацию по частям.
- **Основные результаты проекта (ключевая функциональность):**
  - Статический сайт с удобной навигацией.
  - Описание популярных алгоритмов (сортировки, графы и т.д.) с визуализацией.
  - Примеры кода на Python, C++, Java, JavaScript.
- **Потенциальный рынок и целевая аудитория:** Студенты ИТ-специальностей, начинающие разработчики, участники олимпиад по программированию.
- **Примерные сроки вывода продукта на рынок (MVP и развитие):**
  - MVP: 3-4 недели (базовый набор из 15 алгоритмов).
  - Дальнейшее развитие (добавление новых разделов, интерактивные визуализации): 2-3 месяца.
- **Технологии:** HTML/CSS/JS, React или генераторы статических сайтов (Jekyll / Docusaurus), GitHub Pages.
- **Оценка рисков и технической сложности:**
  - Риски: Трудности в продвижении, большое количество существующих аналогов.
  - Техническая сложность: Низкая (создание статического контента и базовой верстки).
